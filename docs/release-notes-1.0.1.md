# Accounting App 1.0.1 (Pre-release)

إصدار تجريبي مخصص لمنصة Windows و Android، يضيف طبقة المستندات التجارية فوق
نواة Rust المحلية (تخزين SQLite على الجهاز).

## الميزات الجديدة

- **فواتير البيع والشراء**: قائمة، بحث، بطاقات ملخص، محرر أسطر متعدد
  (المادة/الوحدة/الكمية/السعر/الخصم)، حفظ كمسودة، تعديل المسودة، الترحيل،
  عرض التفاصيل، وحذف المسودة مع عكس الأثر.
- **مرتجعات البيع والشراء**: إنشاء وترحيل فوري مع أوضاع تسوية
  `خصم من الدين` / `نقدي كامل` / `تسوية جزئية`.
- **سندات القبض والدفع**: إنشاء سند قبض من عميل أو سند دفع لمورد، مع رقم
  القيد المرتبط وإجمالي المبالغ.
- **بنود المصاريف**: إنشاء وتعديل وحذف بنود مصاريف مع توليد الرمز تلقائياً
  وحصر التعديل على أبناء حساب «مصاريف أخرى».
- **سندات المصروف**: صرف من بند مصاريف عبر نوع سند `ExpenseVoucher` مع
  تحديث رصيد البند.
- **لوحة تحكم**: مؤشرات المبيعات والمشتريات والمصاريف وإجراءات سريعة
  جديدة.
- **البيانات الأساسية**: بطاقات ملخص للعملاء والموردين والمواد.
- **واجهة**: تصميم عربي RTL مستوحى من نسخة React مع خطوط Cairo وسمتان
  فاتحة/داكنة، وشريط أوامر `Ctrl+K`.

## ملفات الإصدار

| الملف | الوصف |
|---|---|
| `accounting-app-1.0.1-windows-x64.zip` | نسخة محمولة (Windows x64) |
| `accounting-app-1.0.1-windows-x64-setup.exe` | مثبّت Inno Setup لكل مستخدم |
| `accounting-app-1.0.1-windows-x64.msi` | مثبّت WiX 3 لكل الأجهزة |
| `app-arm64-v8a-release.apk` | Android 64 بت (arm64-v8a) |
| `app-armeabi-v7a-release.apk` | Android 32 بت (armeabi-v7a) |
| `app-x86_64-release.apk` | Android 64 بت (x86_64) |
| `*.sha256` / `sha256sums.txt` | بصمات SHA-256 لكل ملف |

## التحقق

- Rust: `cargo fmt`، `cargo clippy -D warnings`، و**505 اختباراً** ناجحاً.
- Flutter: `flutter analyze` بلا ملاحظات، و**15/15** اختبار واجهة.
- اختبار تكامل حقيقي على Windows عبر جسر FRB: فاتورة شراء تفتح المخزون،
  فاتورة بيع آجلة، فاتورة بيع نقدية، مرتجع بيع، مرتجع شراء، سند قبض، بند
  مصاريف، سند مصروف، ورفض حذف سند مرحّل.
- المثبّتان: Inno Setup 6.7.3 و WiX 3.14.1 (تثبيت صامت، تشغيل التطبيق،
  وفحص محتوى MSI).

## قيود معروفة

- المرتجعات تُنشأ وتُرحّل فقط؛ لا يوجد تعديل أو عكس لمرتجع مرحّل بعد.
- السندات المرحّلة تُعرض كأثر تدقيقي ولا تُعدّل أو تُحذف.
- الإغلاق المالي، إدارة الشركاء ورأس المال، RBAC، وتبديل اللغة خارج نطاق
  هذا الإصدار.
