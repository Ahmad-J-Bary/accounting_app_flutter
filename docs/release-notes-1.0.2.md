# Accounting App 1.0.2 (Pre-release)

إصدار تجريبي لمنصّات Windows وAndroid و**Linux**، يبني على `1.0.1` ويضيف نظام
واجهة مشتركاً وجداول قابلة للتخصيص ودعم Linux.

## الميزات الجديدة

- **دعم Linux**: حزمة `accounting-app-1.0.2-linux-x64.tar.gz` تُبنى في CI مع
  فحص `ldd` لمكتبة Rust و`libapp.so` واعتمادياتها.
- **جداول قابلة للتخصيص**: تفضيلات مستقلة لكل جدول (إظهار/إخفاء الأعمدة،
  ترتيبها، عرضها، حجم الصفحة) تُحفظ في `table_preferences.json` بجانب
  `accounting.db`، مع شارة على أيقونة الأعمدة تبيّن عدد المخفي وزر
  «إظهار الكل».
- **تنقّل بالكيبورد داخل الجدول**: الأسهم تحرّك مؤشر الصف، و`Home`/`End` و
  `PageUp`/`PageDown` للقفز، و`Enter` لفتح الصف، و`Space` لتحديده، مع إطار
  واضح حول الصف المركّز.
- **فرز مستقر**: الصفوف التي تتساوى فيها قيمة الفرز تحتفظ بترتيبها الأصلي،
  فلا تقفز الصفوف بين الصفحات.
- **خلايا نصية آمنة**: كل خلية بسطر واحد مع `ellipsis`، فلا يتجاوز النص
  الطويل ارتفاع الصف ولا عرض العمود.
- **تخطيط متجاوب**: صفحات العملاء والموردين والمواد تستخدم
  `MasterDataPageLayout`؛ بطاقات المؤشرات تُخفى تحت 720px، وترقيم الصفحات
  يتحول إلى صفّين تحت 520px.
- **صفحات بيانات أساسية منفصلة**: عملاء وموردون ومواد، لكل منها بحث وتصفية
  وحالة فراغ مميزة وتفضيلات مستقلة.
- **تنقّل موحّد**: زر «رجوع»، وسجل تنقّل حتى 50 خطوة، واختصارات
  `Alt+Left`/`Escape`، وشريط أوامر `Ctrl+K`، وتحذير عند مغادرة نموذج فيه
  تغييرات غير محفوظة.
- **توثيق**: دليل معمارية، ودليل نظام التصميم، وأدلة بناء Windows وLinux
  وتوليد FRB.

## ملفات الإصدار

| الملف | الوصف |
|---|---|
| `accounting-app-1.0.2-windows-x64.zip` | نسخة محمولة (Windows x64) |
| `accounting-app-1.0.2-windows-x64-setup.exe` | مثبّت Inno Setup لكل مستخدم |

## التحقق

- Rust: `cargo fmt --all -- --check`، و`cargo clippy --workspace --all-targets
  -- -D warnings`، و**505 اختبارات** ناجحة.
- Flutter: `dart format` نظيف، و`flutter analyze` بلا ملاحظات، و**37/37** اختبار
  واجهة.
- FRB: التوليد مرتين متتاليتين بـ`2.13.0` بلا فرق في الملفات المولّدة.
- CI: `Quality Gates` (Rust + Flutter + FRB) وبناء Windows (ZIP + EXE + MSI
  مع استخراج MSI للتحقق) وبناء Android (ثلاثة APKs) وبناء Linux (الحزمة +
  فحص `ldd`).

## قيود معروفة

- نفس قيود `1.0.1`: المرتجعات تُنشأ وتُرحّل فقط دون تعديل أو عكس، والسندات
  والفواتير المرحّلة تُعرض كأثر تدقيقي لا تُعدَّل، و`RBAC` وإغلاق السنة المالية
  وإدارة الشركاء ورأس المال خارج نطاق هذا الإصدار.
- يبقى الإصدار منشوراً كـ**pre-release** على خط 1.x.
